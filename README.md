# recruitcrm.pro — лендинг Recruit CRM

Статическая страница: `index.html` (HTML, CSS и JS в одном файле, без сборки). Публикуется GitHub Pages из ветки `main`
на https://recruitcrm.pro (файл `CNAME`). Push в `main` = выкладка, через минуту-две.

- Локально: `python3 -m http.server 8080` → http://localhost:8080
- Демо CRM: https://demo.recruitcrm.pro, вход: https://app.recruitcrm.pro/login
- Данные в иллюстрации вымышленные; численные преимущества и отзывы не выдумывать; тарифы и контакт продаж пока не заданы.
- DNS (Dynadot): A `@` → 185.199.108.153 / 109.153 / 110.153 / 111.153; CNAME `www` → mppartners.github.io.

## Счётчик посещений (владелец 16.11.2026, T99)
- `s.js` подключён на всех страницах (`<script defer src="/s.js">` в шапке index.html; база знаний берёт шапку оттуда,
  «Этапы внедрения» — вписан руками). Шлёт события в CRM `https://app.recruitcrm.pro/api/site/event`, статистика — у
  суперадмина CRM на /platform/site.
- Не считать свой браузер: открыть сайт с `?nostats=1` (вернуть — `?nostats=0`). Персональная ссылка: `?от=имя`.
- Новая страница сайта считается, только если её путь добавлен в `SITE_PAGES` в CRM (src/server/site/visits.ts).
- Строка в подвале о сборе статистики обязательна (ревью admin).
